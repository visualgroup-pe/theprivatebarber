# The Private Barber · Paquete de referencia para Claude Code

Contenido
- diseno/  Diseño aprobado en HTML (formato del lienzo: <x-dc>, {{huecos}} y un script DCLogic).
  Úsalo como referencia visual y de textos; no es código de producción.
  - Main.dc.html: portada (fluida). El hero usa {{heroImg}}: por defecto img/espacio-silla.jpg.
  - Resenas.dc.html: página de reseñas.
  - Movil-1..4: flujo de solicitud de cita en móvil (390 x 844).
- img/  Fotos tratadas (cálidas, algo desaturadas) y la textura grano.png.
- marca/ Logotipos y monogramas en SVG (el paquete completo está en TPB_Identidad_Visual_v2.zip).
